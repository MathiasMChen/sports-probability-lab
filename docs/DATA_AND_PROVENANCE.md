# Data, provenance and publication boundary

## Included

- Newly curated, compact reference implementations of model families used in the broader project.
- Anonymous data generated entirely by a deterministic NumPy random generator. Synthetic team IDs, dates, outcomes, margins, rates and comparator probabilities are illustrative.
- A reproducible synthetic report, an environment snapshot, and an SVG calibration figure generated by the demo.
- Selected historical aggregate research summaries in CASE_STUDIES.md, transcribed from reviewed project documentation. They are labelled retrospective and cannot be regenerated from the public synthetic data.

## Excluded

No operational repository history, archive pointers, linked-workspace IDs, account balances, individual tickets, approvals, research/execution archives, credentials, source-page caches, production fitted coefficients, or private runtime manifests are included. There is no external data connector, scraping command, betting-platform integration, telemetry, or production scheduler.

An initial public history is created from these selected files. The operational Git history is not copied or merged. Future updates should maintain this boundary.

## Reproducibility

The demo fixes its random seeds, records training/test boundaries, and writes finite JSON. Re-running in the same numerical environment should reproduce the checked-in output. SciPy optimizer or floating-point changes across versions may alter the final digits. See results/environment.json for the generation environment.

The reference code is not an exact numerical replay of the operational models. The synthetic noisy comparator is not a real bookmaker; model-minus-comparator results are demonstrations of the evaluation workflow only. No historical match data is redistributed, and no third-party data licence is inferred from this repository's visibility.

## References

- Bradley–Terry paired-comparison models: relative strength from pairwise outcomes.
- Dixon–Coles football score models: low-score dependence adjustments to independent Poisson goals.
- SciPy documentation: [binomial](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.binom.html), [beta-binomial](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.betabinom.html), [Poisson](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.poisson.html).

AI coding assistance was used to prepare this public implementation and its documentation. Historical case-study statements are kept separate from newly executed software checks and synthetic experiments.
